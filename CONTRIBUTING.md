# Contributing

Thank you for considering an improvement to this portfolio.

## Workflow

1. Fork the repository or create a feature branch.
2. Keep changes focused and use descriptive commit messages.
3. For visual changes, check the page at desktop and mobile viewport widths.
4. Verify that navigation links work and that new images have meaningful alternative text.
5. Open a pull request with a concise summary, screenshots for UI changes, and the checks you performed.

## Quality Guidelines

- Preserve the existing design and responsive behavior unless the change explicitly targets them.
- Avoid committing credentials, API keys, personal data, or generated build artifacts.
- Prefer semantic HTML and accessible labels, keyboard navigation, and sufficient contrast.
- Keep documentation accurate and update it when behavior or setup instructions change.

## Reporting Issues

When opening an issue, include the page affected, reproduction steps, expected behavior, and actual behavior. Remove any private information from screenshots or logs.
