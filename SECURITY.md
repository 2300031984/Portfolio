# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this portfolio website, please report it privately to the repository owner through GitHub's private vulnerability reporting feature, if enabled, or by direct contact through the profile linked from the site.

Please include:
- The affected page or component
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigation

## Responsible Disclosure

Do not publicly disclose an unpatched vulnerability or access, modify, or delete data that does not belong to you. Test only systems and accounts you own or have explicit permission to assess.

## Scope

This policy covers the portfolio website and its repository. Third-party services and platforms are governed by their own security policies.
